# Objection Handling Guide — TechNova Sales

## Philosophy

Objections signal engagement. Use **Listen → Acknowledge → Clarify → Respond → Confirm** (LACRC) before discounting.

## Common Objections

### "Too expensive"

- Clarify: compared to what? build vs buy, headcount, risk.
- Anchor on ROI: average customer saves **40 hours/month** per team on internal search.
- Offer phased rollout: pilot department → expand.
- Never discount more than **15%** without Sales Director approval.

### "We already use Confluence / SharePoint"

- Position TechNova as **cross-tool search** with AI answers, not replacement day one.
- Highlight permissions-aware retrieval competitors lack.
- Propose integration roadmap (Confluence connector Q3).

### "Security / compliance concerns"

- Share SOC 2 Type II report (under NDA).
- Reference `security_policy` themes: encryption, RBAC, audit logs.
- Offer private VPC deploy for Enterprise tier.

### "Need to think about it"

- Set concrete next step with date.
- Identify blocker: budget, champion, technical validation?
- Offer 14-day POC with success criteria document.
